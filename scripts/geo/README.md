# `web/scripts/geo/` · 地图矢量数据存档

> **本目录只存原始资料，不参与前端构建。** 前端消费的是由这些数据经中国标准 Albers 投影（25°N / 47°N，中央经线 105°E）一次性固化的 `web/src/utils/cities.ts` 与 `web/src/utils/chinaMapData.ts`（原构建脚本已随 `RC-95` 退役）。
> **唯一权威的合规要求见 [`docs/wishlist-travel.md`](../../../docs/wishlist-travel.md) §六。**

## 数据来源

| 项 | 值 |
| :--- | :--- |
| **来源** | **阿里云 DataV GeoAtlas 行政区划服务**（`https://geo.datav.aliyun.com/areas_v3/bound/`） |
| **上游** | 阿里云官方声明：该数据**来自高德开放平台** |
| **获取方式** | HTTP 直接下载（`{adcode}_full.json`），无需 key |
| **获取时间** | **2026-10-11** |
| **许可** | DataV 官方声明「**仅供学习和交流使用，不得用于商业目的**」；商业用途须自行向高德开放平台获取授权 |

> ⚠️ **若本项目将来涉及商业用途**，须改用 [`www.webmap.cn`](https://www.webmap.cn)（自然资源部主管 · 国家基础地理信息中心 · 1:100 万公众版，需注册，格式为 Shapefile），或向高德取得正式授权。

## 文件清单（共 34 个）

- **`100000_full.json`** —— **全国省级边界**（582 KB）
  - 34 个省级行政区：23 省 + 5 自治区 + 4 直辖市 + **台湾省 `710000`** + **香港 `810000`** + **澳门 `820000`**
  - 外加 **`100000_JD`** —— **南海断续线（10 段）**，即地图上那条「十段线」，坐标为官方数据，**不必手绘**
- **`{省级 adcode}_full.json` × 33** —— 各省下辖**地级市**边界
  - 台湾 `710000` 无下级的 `_full.json`（行政层级不同），属正常
  - 港澳有 `_full.json`（为其下辖区）

## 用途

1. **来源凭据**：`wishlist-travel.md` §六.4 要求「必须注明数据来源、获取方式与固化日期」——**本目录即该凭据**。
2. **离线备份**：保留全部 34 个省级与地级市原始 GeoJSON，未来若需重新生成（换数据源 / 调投影 / 区划调整），可据此重写生成器复现产物。
3. **边界唯一来源**：省级轮廓、地级市轮廓、**南海断续线**均取自本目录数据；**禁止手绘**（§六.4）。

## 与审图的关系

本目录只解决「**数据从哪来**」。**向社会公开地图仍须先通过地图审核**（自制全国地图须经自然资源部审核）——详见 [`docs/wishlist-travel.md`](../wishlist-travel.md) §六.6 / §六.7 及其后的送审材料清单。
